# Quickstart: 小红书风格内容社区前端— 验证指南

**Feature**: [spec.md](./spec.md) | **Date**: 2026-08-07

本指南用于验证「小红书风格内容社区前端」改造完成后的端到端功能是否符合预期。全程通过 **Mock 模式**验证，无需依赖后端服务运行。

## 前置条件

- Node.js 已安装（当前环境提示缺失，需先安装：https://nodejs.org/，建议 LTS 版本 ≥ 18）
- 已切换到 `frontend/` 目录

## 环境准备

```bash
cd frontend
npm install
```

创建/确认 `.env.local`（或直接用环境变量）启用 Mock 模式：

```bash
echo "VITE_USE_MOCK=true" > .env.local
```

## 启动开发服务器

```bash
npm run dev
```

访问 `http://localhost:5173`。

## 验证场景（对应 spec.md 的 6 个 User Story）

### 场景 1：首页瀑布流浏览（P1）

1. 打开首页 `/`，登录（Mock 模式下任意用户名密码可登录，或参考 `src/mock/index.ts` 预置账号）
2. **预期**：看到多列瀑布流卡片（桌面宽屏 ≥1200px 应为 4-5 列，卡片高度随图片比例错落排列）
3. 切换浏览器窗口宽度至 ≤560px（或用浏览器设备模拟器），**预期**：瀑布流自动收敛为 2 列
4. 滚动到页面底部，**预期**：自动加载更多卡片，出现短暂加载指示（骨架屏或加载文案）
5. 点击顶部「推荐」/「关注」/「同城」Tab，**预期**：内容切换，选中 Tab 高亮为品牌色胶囊背景

### 场景 2：帖子详情与互动（P1）

1. 点击任意瀑布流卡片，**预期**：跳转到 `/feeds/:feedId`，展示完整标题/正文/媒体/作者信息
2. 点击点赞按钮，**预期**：图标从空心变为实心（或颜色变化），点赞数 +1，响应时间 < 100ms 感知
3. 点击收藏按钮，**预期**：同上逻辑
4. 若非本人帖子，点击「关注」，**预期**：按钮态切换为「已关注」

### 场景 3：评论楼中楼（P2）

1. 在帖子详情页底部输入框输入评论内容，回车或点击发送，**预期**：评论出现在列表顶部
2. 点击某条评论的「回复」，**预期**：输入框显示「回复 @昵称」提示
3. 若某评论有多条子回复，点击「展开全部 N 条回复」，**预期**：加载并展示全部子回复

### 场景 4：个人主页（P2）

1. 点击任意卡片作者头像，**预期**：跳转到 `/users/:userId`，展示头像/昵称/简介/统计数据
2. 该用户的帖子以**等宽网格**（非瀑布流）展示
3. 点击「关注」数字，**预期**：跳转关注列表页

### 场景 5：发布帖子（P2）

1. 点击首页右下角 FAB（+ 按钮），**预期**：跳转`/publish`
2. 不上传媒体直接点击发布，**预期**：提示「请先上传图片或视频」
3. 上传图片后填写描述并点击发布，**预期**：按钮显示「发布中…」并禁用，成功后跳转新帖子详情页

### 场景 6：登录注册（P3）

1. 未登录状态访问 `/`，**预期**：自动跳转 `/login`
2. 登录成功后，**预期**：跳转回原目标页面（redirect 参数生效）

## 视觉与响应式验收清单

对照 `DESIGN.md` 更新后的规范，人工检查：

- [ ] 无硬编码颜色/字号/间距/圆角（可用浏览器 DevTools 检查计算样式是否引用 CSS 变量）
- [ ] 桌面端（>1024px）、平板（768-1024px）、移动端（≤560px）三种视口下均无布局错乱
- [ ] 所有可交互元素可通过 Tab 键聚焦，`focus-visible` 轮廓可见
- [ ] 图片加载失败时显示占位色而非破损图标
- [ ] 系统开启「减弱动态效果」时，所有过渡动画被禁用（`prefers-reduced-motion`）


## 安全自检（对应 spec FR-018~021）

- [ ] 全局搜索代码库确认零 `dangerouslySetInnerHTML` 与 `eval` 调用
- [ ] 检查 Network 面板，确认所有 ID 字段（如 `feed.id`、`user.id`）在浏览器 Console 打印时为字符串而非丢失精度的number
- [ ] 确认 `.env*` 文件中不含任何密钥（仅 `VITE_GATEWAY_TARGET`/`VITE_USE_MOCK`）
- [ ] 手动使无效 token 触发 401，确认自动跳转登录页且提示文案清晰
